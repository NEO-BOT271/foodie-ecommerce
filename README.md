# Foodie – E-Commerce Food Ordering App

A full-stack Angular application for browsing menus, managing user accounts, and completing food orders with secure authentication.

## Features
- **User Authentication:** Registration, login, password management (change password, forgot password)
- **Account Management:** User profile, delete account
- **Shopping Cart:** Add/remove items, view cart, proceed to checkout
- **Menu Browsing:** View food items, filter by category

## Tech Stack
- **Frontend:** Angular 21, TypeScript, SCSS
- **Backend:** RESTful API (Provided by IT STEP Academy)
- **Authentication:** Bearer Token Authentication (JWT-based)
- **Database:** Managed by Backend API
- **Deployment:** Vercel
